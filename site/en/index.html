MuM = Multi-project Markdown

A reading-first Markdown engine.
Fast, native For humans, and for agents.

MuM is a Markdown engine built just for the Mac: hand-set typesetting in AppKit, tiny and blazing fast; multiple projects open in parallel with instant switching; and agents can call it directly to get rendered output or JSON data.

For humans

  • Multi-project — keep several projects open, switch with ⌘1…⌘9. Projects answer “where am I”.
  • Built for reading — remembers where you stopped, ⌘F find, ⌘⇧O outline, reading history on ⌘[ ⌘].
  • Find anything — ⌘P fuzzy-finds files by name; ⌘⇧F searches names and contents across every project, streaming results.
  • CJK-tuned typesetting — line height, punctuation compression, and mixed-script spacing are measured, not guessed.
  • Export — ⌘⇧E turns the current document into a tall PNG or a paged PDF; page-break hints in the document become real page breaks.
  • Quiet — no accounts, no telemetry, no plugin store. A tool shouldn't be louder than its content.

Day to day

  • Single-file mode — double-click a lone file and both sidebars fold away: just read. The folder isn't turned into a project; your project list stays clean.
  • File management — ⌘N new file, new folder, rename, move to Trash — all in the file tree's ··· and right-click menus.
  • Open in Terminal — one click opens a shell right at a deeply nested folder; auto-detects Ghostty → iTerm → Terminal.app.
  • Reads a lot — code highlighting, CSV/TSV as tables, RTF, images, PDF, srt/vtt subtitles; Office files get a page that points to the default app.
  • One-click updates — hit “Download update” on the banner: the DMG downloads in-app, mounts itself, and you drag MuM into Applications.
  • HTML in Markdown — <small>, <mark>, super/subscripts render semantically; the tags themselves stay out of sight.

For agents

  • Windowless rendering — the same hand-built typesetting engine (CJK spacing, code highlighting, reading themes), straight to PNG / PDF from the CLI.
