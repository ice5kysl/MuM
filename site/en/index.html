For humans

  • Multi-project —— Several projects open at once, ⌘1…⌘9 to switch. Projects answer “where am I”.
  • Made for reading —— Remembers where you were, ⌘F find, document outline, cross-project search.
  • Typographic tuning for CJK —— Line height, punctuation, CJK/Latin spacing — all measured, not guessed.

For agents

  • Headless rendering —— mum render --png — the same typesetting engine.
  • Structured output —— outline / search emit --json with meaningful exit codes.
