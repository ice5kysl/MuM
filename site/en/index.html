MuM = Multi-project Markdown

A fast, native Markdown engine. For humans, and for agents.

No web engine, no plugin system, no accounts. A 3.2 MB AppKit app that opens straight into reading — and the same typesetting engine renders for agents from the command line.

For humans

  • Multi-project — keep several projects open, switch with ⌘1…⌘9. Projects answer “where am I”.
  • Built for reading — remembers where you stopped, ⌘F find, ⌘⇧O outline, reading history on ⌘[ ⌘].
  • Find anything — ⌘⇧F searches file names and contents across every project, streaming results as it scans.
  • CJK-tuned typesetting — line height, punctuation compression, and mixed-script spacing are measured, not guessed.
  • Export — ⌘⇧E turns the current document into a tall PNG or a paged PDF.
  • Quiet — no accounts, no telemetry, no plugin store. A tool shouldn't be louder than its content.

For agents

  • Windowless rendering — the same hand-built typesetting engine (CJK spacing, code highlighting, reading themes), straight to PNG / PDF from the CLI.
$ mum render README.md --png cover.png
rendered README.md → cover.png (768 KB)

$ mum outline README.md --json
[
  { "level": 1, "location": 0, "title": "MuM 渲染自检" },
  { "level": 2, "location": 52, "title": "一、标题层级" }
]

Output of mum render (excerpt): a fully typeset tall image. outline / search / check emit stable JSON with classified exit codes (0/1/2/3/4) — agents never parse prose.
