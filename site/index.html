MuM = Multi-project Markdown

阅读优先的 Markdown 引擎。 给人用，也给 agent 用。

MuM 是专为 macOS 打造的 Markdown 引擎：用 AppKit 手写排版，体积小、速度超快； 多项目并行打开、快速切换；也支持 agent 直接调用，输出渲染结果或 JSON 数据。

给人用

  • 多项目 —— 几个项目同时开着，⌘1…⌘9 秒切。项目回答「我在哪」。
  • 读得进去 —— 记住上次读到哪，⌘F 查找，⌘⇧O 大纲，阅读历史 ⌘[ ⌘] 来回跳。
  • 找得到 —— ⌘P 按名字模糊找文件；⌘⇧F 跨所有项目搜文件名和内容，边搜边出。
  • 排版按中文调过 —— 行距、标点挤压、中英混排间距，都是实测出来的数值。
  • 导出 —— ⌘⇧E 把当前文档出成 PNG 长图或分页 PDF；文档里的分页指令导出时真正换页。
  • 安静 —— 无账号、无上报、无插件商店。工具不该比内容更吵。

日常用起来

  • 单文件模式 —— 双击落单的一份文件，两栏收起、直接读 —— 不会把所在文件夹开成项目，你的项目列表干干净净。
  • 文件管理 —— ⌘N 新建、新建文件夹、重命名、移到废纸篓，都在文件树的 ··· 和右键菜单里。
  • 在终端中打开 —— 深目录一键就地开终端：按 Ghostty → iTerm → 系统终端自动探测你装了的那个。
  • 读得杂 —— 代码高亮、CSV/TSV 按表格、RTF、图片、PDF、字幕 srt/vtt；Office 这类给「用默认应用打开」的导向页。
  • 一键更新 —— 新版本提示条上点「下载更新」，DMG 自己下载、自动挂载，拖进「应用程序」就完事。
  • Markdown 里的 HTML —— <small> 缩小、<mark> 高亮、上下标都按语义排版，标签不露出来。

给 agent 用

  • 无窗口出图 —— 同一套手写排版引擎（CJK 间距、代码高亮、阅读主题），命令行直接出 PNG / PDF。
$ mum render README.md --png cover.png
已渲染 README.md → cover.png（768 KB）

$ mum outline README.md --json
[
  { "level": 1, "location": 0, "title": "MuM 渲染自检" },
  { "level": 2, "location": 52, "title": "一、标题层级" }
]

outline / search / check 输出稳定 JSON，退出码 0/1/2/3/4 分类——agent 不用解析文本。
