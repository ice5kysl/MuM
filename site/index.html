MuM

A fast, native Markdown engine. 给人用，也给 agent 用。

没有 Web 引擎，没有插件系统，没有账号。打开就是读。

签名并公证，双击即开，不需要右键绕过 Gatekeeper。

给人用

  • 多项目 —— 同时开着几个项目，⌘1…⌘9 秒切。项目回答「我在哪」。
  • 读得进去 —— 记忆阅读位置、⌘F 查找、文档大纲、跨项目搜索。
  • 排版按中文调过 —— 行距、标点、中英混排间距都是实测出来的。

给 agent 用

  • 无窗口出图 —— mum render --png，同一套排版引擎。
  • 结构化输出 —— outline / search 输出 --json，退出码有意义。
