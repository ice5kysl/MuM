## 一、口径（2026-09-28 定）

> **「冷启动到窗口上屏」= `release` 包（用户实际下载到的那个），双击语义（app 未运行 + 带一个 1 MB 文档），
> 同机对拍，**n ≥ 5**，报**中位数与区间**，并注明机器负载。**

**为什么必须是 release 包**：`scripts/measure-ttfr.sh` 历来默认量 `debug` 包，而 debug 包没有优化 ——
用户拿到的不是那个。两者差别在"首屏已写入"上尤其大（debug ~690ms vs release ~528ms）。
脚本 2026-09-28 加了 `CONFIG=release`：

```bash
CONFIG=release scripts/measure-ttfr.sh 1 v0.7.9    # 报数用这个
scripts/measure-ttfr.sh 1 v0.7.9                    # 默认 debug，只作历史对照
```

**为什么必须报 n 与区间**：单点测量在这台机器上不可信（判定按区间不按单点，2026-09-18 定的规矩）。
